# Web Tasarım Freelance — Modüler Fiyatlandırma Sistemi

**Ekip:** Mehmet Akif Akkaya (satış, müşteri ilişkileri) + Dündar Dinç (tasarım, teknik, proje yönetimi)

**Felsefe:** Müşteri neyi isterse o kadarını öde — tek index sayfası mı, çok sayfası mı, reklam mı, e-commerce mi, hepsi ayrı modüler.

> 📌 **Görsel tablo:** https://claude.ai/code/artifact/f1480a49-1238-4a36-a7bb-4db3f9a0e7a1

## 1. BASE SITE (Anahtar Teslim - Tek Index Sayfası)

Domain + DNS + canlıya alma dahil. Hızlı iş, kısa hazırlanma.

| Paket | Tasarım Tipi | Hazırlanma | Fiyat |
|---|---|---|---|
| **Basic** | Basit vitrin: header + tanıtım görseli + kartlar + iletişim footer. Responsive garanti, hover efektleri. Profesyonel tasarım/renk paleti değil. | 2-3 gün | **3.500₺** |
| **Standart** | Slider, FAQ, testimonials, profesyonel layout. *SEO kurulumu opsiyonel: +1.500₺* | 4-7 gün | **5.500₺** |
| **Premium** | Video hero, parallax scroll, animations, custom illustrations, glassmorphism | 10-14 gün | **12.500₺** |

### Basic Paket — Teknik Kapsam

**Amaç:** Müşterinin işini tanıtan + iletişim bilgisi sunan basit vitrin. Ziyaretçiyi müşterinin kendisine yönlendirir. Profesyonel tasarım hedefi yok.

- Tek index sayfası (ek sayfa yok)
- Yapı: 1 header → tanıtım görseli (hero, profesyonel tasarım değil) → kartlar → iletişim footer
- Basit logo yapımı
- Responsive garanti (Basic'te bile), kart/buton hover efektleri
- Standart renk paleti (profesyonel olması şart değil)
- Domain + canlıya alma dahil
- **Opsiyonel Basit Destek — 1.000₺:** hata düzeltme, içerik & görsel değiştirme, iletişim bilgisi güncelleme *(aylık mı / talep başı mı — netleştirilecek)*

## 5. ÖRNEK SİPARİŞ HESAPLAMALARI

### Örnek 1: Kuaför (Basit)
- Base Site (Basic): 3.500₺
- Sayfa Ekleme (2 sayfa - Hizmetler, İletişim): 1.000₺ × 2 = 2.000₺
- **Toplam:** 5.500₺ (anahtar teslim)
- Aylık (Bakım + Reklam): 1.000₺ + 800₺ = 1.800₺/ay

### Örnek 2: Kafe (Orta)
- Base Site (Standart): 5.500₺
- Sayfa Ekleme (3 sayfa - Menü, Galeri, İletişim): 1.500₺ × 3 = 4.500₺
- Reklam Yönetimi eklenirse: +1.500₺/ay
- **Toplam:** 10.000₺ (anahtar teslim)
- Aylık: 1.200₺ (Bakım) + 1.500₺ (Reklam) = 2.700₺/ay

### Örnek 3: Çevrimiçi Satış (Kompleks)
- Base Site (Premium): 12.500₺
- Sayfa Ekleme (4 sayfa): 2.500₺ × 4 = 10.000₺
- E-Commerce (Premium): +10.500₺
- **Toplam:** 33.000₺ (anahtar teslim)
- Aylık: 1.500₺ (Bakım Premium) + 1.700₺ (E-Commerce) + 2.500₺ (Reklam) = 5.700₺/ay + satış komisyonu

## İŞ AKIŞI

1. **Müşteri Kazanım (Akif):** Esnafa git, ihtiyaçlarını dinle, hangi modülü istediğini anla
2. **Teknik Plan (Dündar):** Seçilen modülleri hesapla, teklif sun
3. **Tasarım & Geliştirme (Dündar):** Modullar doğrultusunda site yap
4. **Aylık Destek (Dündar):** Seçilen subscription paketlerine göre çalış

---

## AÇIKLAMALAR

- Her şey **modüler**: müşteri sadece index isterse 2k, 10 sayfa + e-commerce isterse 30k
- **Hazırlanma süresi** sadece seçilen paketler için geçerli (Base + Sayfalar)
- **Aylık abonelikler** bağımsız, müşteri dilerse hiçbirini seçmeyebilir, dilerse tümünü seçebilir
- **E-commerce commission:** Payment gateway (Stripe, PayPal vb) ücretinden %1-2,5 kesintisi Akif ve Dündar arasında bölünür

## İş Akışı

### Müşteri Kazanım (Akif)
1. Hedef esnaf belirleme (kuaför, kafe, klinik vb.)
2. Yüz yüze prezentasyon (tablet demo + paket seçenekleri)
3. Sipariş alınca Dündar'a devretme

### Tasarım & Teknik (Dündar)
1. Müşteri briefi al
2. Şablon seç / özelleştir
3. Tasarım tamamla
4. Domain satın al (müşteri adına)
5. Canlıya al ve test et
6. Teslim

### Aylık Destek (Dündar)
- Content update, monitoring
- Reklam yönetimi (varsa)
- Performans raporları
